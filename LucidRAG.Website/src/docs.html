Get Started

Documentation

Get up and running with LucidRAG quickly

Quick Start

1

Clone the Repository

git clone https://github.com/scottgal/LucidRAG.git
2

Install Dependencies

cd LucidRAG && dotnet restore
3

Configure Settings

Edit appsettings.json to configure your LLM backend and vector store.

"DocSummarizer": {
  "Ollama": { "BaseUrl": "http://localhost:11434" }
}
4

Build and Run

dotnet build && dotnet run --project src/LucidRAG/LucidRAG.csproj
5

Open in Browser

Navigate to https://localhost:5020 and start uploading documents!

Configuration Reference

LLM Backend

Choose between local Ollama or Anthropic/OpenAI

"DocSummarizer": {
  "Ollama": {
    "BaseUrl": "http://localhost:11434",
    "Model": "llama3:8b"
  }
}

Vector Store

DuckDB (local) or Qdrant (persistent)

"DocSummarizer": {
  "BertRag": {
    "VectorStore": "DuckDB" // or "Qdrant"
  }
}

Database

PostgreSQL (production) or SQLite (standalone)

"ConnectionStrings": {
  "DefaultConnection": "Host=localhost;Database=lucidrag;..."
}

Prompts

Configure query processing behavior

"Prompts": {
  "Clarification": true,
  "Decomposition": true,
  "SelfCorrection": true
}
