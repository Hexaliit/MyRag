Frequently Asked Questions

When will pricing be announced?

Pricing is to be determined (TBD) as the project is currently in development. Please check back for updates or contact us via GitHub issues for more information.

Can I try the features before upgrading?

Yes! The Free tier includes all core processing capabilities. You can test all 5 pipelines, 22-wave image analysis, and GraphRAG before deciding to upgrade.

What happens if I exceed the 50 document limit?

On the Free tier, you'll need to either delete documents or upgrade to the Professional tier with the "Unlimited Documents" feature to continue adding more.

Can I change my Professional configuration later?

Yes! You can add or remove features at any time. Pricing is pro-rated based on your active configuration.
