# Mostlylucid.LucidRAG.CodeSummarizer.Mermaid.Jint

Mermaid diagram parsing using Jint (runs mermaid.js in-process) for spec-conformant parsing and richer structure extraction.

## Install

```bash
dotnet add package Mostlylucid.LucidRAG.CodeSummarizer.Mermaid.Jint
```

## Notes

This package is designed as a drop-in replacement for regex-based Mermaid parsing in the CodeSummarizer pipeline.
