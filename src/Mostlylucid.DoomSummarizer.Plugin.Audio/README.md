# Mostlylucid.LucidRAG.Plugins.Audio

Audio analysis plugin for DoomSummarizer. Provides speech-to-text transcription
and speaker diarization for audio files.

## Supported Extensions
.mp3, .wav, .flac, .ogg, .m4a, .opus

## CLI Commands
- `doomsummarizer audio transcribe <file>` - Transcribe audio to text
- `doomsummarizer audio speakers <file>` - Identify and separate speakers
