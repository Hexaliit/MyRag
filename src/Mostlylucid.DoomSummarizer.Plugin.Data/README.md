# Mostlylucid.LucidRAG.Plugins.Data

Data analysis plugin for DoomSummarizer. Provides statistical profiling,
schema detection, and constraint validation for tabular data files.

## Supported Extensions
.csv, .xlsx, .xls, .parquet, .json, .jsonl, .tsv

## CLI Commands
- `doomsummarizer data profile <file>` - Run statistical profiling
- `doomsummarizer data schema <file>` - Detect and display schema
