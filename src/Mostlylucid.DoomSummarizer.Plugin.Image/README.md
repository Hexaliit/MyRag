# Mostlylucid.LucidRAG.Plugins.Image

Image analysis plugin for DoomSummarizer. Provides OCR, captioning,
and multi-wave ML analysis for image files.

## Supported Extensions

.png, .jpg, .jpeg, .gif, .webp, .bmp, .tiff

## CLI Commands

- `doomsummarizer image analyze <file>` - Run full 22-wave analysis
- `doomsummarizer image ocr <file>` - Extract text via OCR
- `doomsummarizer image caption <file>` - Generate vision model caption
