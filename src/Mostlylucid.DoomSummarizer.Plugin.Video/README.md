# Mostlylucid.LucidRAG.Plugins.Video

Video analysis plugin for DoomSummarizer. Provides shot detection, scene segmentation,
and transcription support for video files.

## Supported Extensions

.mp4, .mkv, .avi, .webm, .mov, .wmv

## CLI Commands

- `doomsummarizer video analyze <file>` - Run full video analysis pipeline
- `doomsummarizer video shots <file>` - Detect shot boundaries
- `doomsummarizer video scenes <file>` - Segment video into scenes
